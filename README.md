# CubeZero
An algorithm designed to solve both the 3×3×3 Rubik's Cube and the 2×2×2 Rubik's Cube.

# How to use this program:
Step 1: After downloading the program, go to the AlphaCube/data folder. Find the file depth5_database.pkl.zip and extract the compressed file. Make sure to delete the .zip file after extraction.

Step 2: Go to the CubeZeroApp folder and find run_cubezero.command and run_cubezero_windows.bat. The first file is for Mac users, while the second is for Windows users. Click on the appropriate file to launch the app.

Note: Sometimes, it may take two or three attempts to open the app. If nothing happens, terminate the process and try again.
